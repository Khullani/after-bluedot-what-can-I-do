# Changelog

Records of cohorts that have used this playbook and what the participants
chose to ship. Adapted from the format in
[agi-strategy-government](https://github.com/Khullani/agi-strategy-government).

The repo is a living document — see
[`CONTRIBUTING.md`](./CONTRIBUTING.md) for how to add your cohort, your
shipped artifacts, or a new archetype.

## Format

For each cohort:
- **Cohort:** course name + dates
- **Participants:** count (names omitted unless they've made their
  involvement public)
- **Archetypes chosen:** what each person picked
- **Shipped (v1):** links to anything publicly published
- **Lessons:** notes for the next cohort

## How to contribute to this changelog

If you used this menu and shipped something, open a PR adding your
project to the appropriate cohort entry. Include:

1. Which archetype you picked.
2. Link to the v1 deliverable (repo, op-ed, memo if public, etc).
3. One sentence on what worked and what didn't.

I'll link back from the menu in [`README.md`](./README.md) so future
cohorts can see live examples.
