# Public Debate — The Before/After Vote

The vote is the engine of the event. Measure the room before any argument,
again at the end, and reveal the shift.

## Build it

- Use **one audience-polling event** with **two identical polls**. Build poll
  #1, then duplicate it for poll #2. Identical wording is critical or the
  comparison breaks.
- **Poll type:** multiple choice, single answer.
- **Question:** the motion, phrased so the options map to sides — for example,
  *"Should we [MOTION]?"*
- **Options:** use a scale so you can see movement, not just a flip:

  1. Strongly support
  2. Somewhat support
  3. Undecided
  4. Somewhat oppose
  5. Strongly oppose

## Run it

1. Open **poll #1** at the top. Give about 30 seconds.
2. **Lock it and hide the results.** This prevents anchoring and makes the
   reveal land.
3. After closing statements, open **poll #2** for the same amount of time.
4. **Compare the results:** use a built-in comparison view when available;
   otherwise reveal the two polls sequentially or prepare a slide with the
   final numbers side by side. *"Here's where we started — and here's where we
   landed."*

## Choose the tool

Slido, Mentimeter, and similar audience-response tools can all support this
flow, but their comparison features and free-tier participant, question, and
presentation limits differ and change over time. Check the current official
plan limits for your expected audience before you announce the tool or print
the join code. If needed, budget for an event plan. Do not assume a plan sold
as a monthly price can be purchased for only one month.

Put the join QR code and short code on the vote screen graphic, and keep a
plain-text short link as a fallback.

## Don't skip

**Rehearse the full flow from a phone before the event.** Confirm that you can
open, lock, hide, duplicate, and reveal or compare the polls with the account
and plan you will use on the night. Use a small test group and check whether
test participants count toward your allowance. Never reset the first poll;
you will lose the “before.” Always use two separate polls.
