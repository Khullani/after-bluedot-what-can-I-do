# Templates

Starter scaffolds for each archetype in [`../PLAYBOOK.md`](../PLAYBOOK.md).
Copy the one you need, fill it in, throw away the parts that don't fit.

## General

- [`project-brief.md`](./project-brief.md) — one-page scoping doc to fill out
  before you start any archetype. If you can't fill in the brief, you don't
  have a project yet.

## A note on using these

These are skeletons, not constraints. The structure is the part worth keeping;
the specific phrasing is mine and won't sound right in your voice. Rewrite as
you fill in.

If you find a structure that works better than what's here, open a PR. The
templates improve as the cohorts use them.
