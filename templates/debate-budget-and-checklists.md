# Public Debate — Budget + Checklists

## Lean budget template

| Line item | Estimate | Notes |
|---|---|---|
| Venue | $[0] | Often free with a partner in exchange for visibility |
| Debater travel | $[ ] | Flight + hotel; often needed for only one speaker |
| Debater honoraria | $[0] | Optional |
| Catering / reception | $[ ] | A sponsor can cover this |
| Printing (badges, poster, tents, roster) | $[50–150] | Print at 100%; test badge alignment on plain paper first |
| Voting tool | $[ ] | Check current free-tier limits or price an appropriate one-time/event plan |
| Signage / miscellaneous | $[ ] | |
| **Total** | **$[ ]** | Often a few hundred dollars before travel/catering with an in-kind venue partner |

**Potential funding sources:** an in-kind venue partner, a cash sponsor for the
series, and grants available to local AI-safety organizers. Check current
eligibility, award sizes, and turnaround times before promising funds.

---

## Countdown checklist

### ~8 weeks

- [ ] Motion chosen
- [ ] Venue + date locked
- [ ] Debater outreach started (build a bench)
- [ ] Sponsor conversations opened

### ~6 weeks

- [ ] Four debaters confirmed (two for / two against)
- [ ] RSVP page live
- [ ] Communications suite drafted

### ~4 weeks

- [ ] Promotion push underway
- [ ] Moderator prep underway
- [ ] Format + run of show locked

### ~2 weeks

- [ ] Venue logistics and photography/recording policy confirmed in writing
- [ ] On-site assets generated + printed (plain-paper test first)
- [ ] Crew briefed

### ~1 week

- [ ] Voting flow rehearsed from a phone
- [ ] Moderator prep packet finalized
- [ ] RSVP reminder sent

### Day of

- [ ] Setup + sound check complete
- [ ] Cards, roster, badges, and vote screen in place
- [ ] Photographer/recorder briefed on the agreed policy
- [ ] Run the show

### After (within ~2 weeks)

- [ ] Send 1:1 thank-yous to debaters, venue, and sponsors
- [ ] Send attendee thank-you (+ a warm missed-you line for no-shows)
- [ ] Publish a recap
- [ ] Send the post-event intake form and build the follow-up list
